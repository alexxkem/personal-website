# Personal Website

This is my personal website that I built using HTML and CSS. I made this website to have a place where I can share some of my projects, skills, and information about myself.

I also wanted to get more practice with web development and learn how to build and style a website from scratch.

## Features

- A homepage with a short introduction about myself.
- An About Me section with more information about my background.
- A projects section that shows some of the projects I've worked on.
- Links to my GitHub, LinkedIn, and email.
- A button to view my resume.
- Navigation buttons to jump to different sections of the website.

## Technologies Used

- HTML
- CSS
- GitHub Pages

## How It Works

The website is built using HTML for the structure and CSS for the styling. I separated the website into different sections, such as About Me and Projects, to make it easier for visitors to navigate.

I also added buttons and links so visitors can view my resume, check out my projects, or contact me.

The website is hosted using GitHub Pages, so anyone can access it online.

## How to Run

1. Clone or download the repository.
2. Open the `index.html` file in your browser.
3. You can also visit the website using the link below.

This project helped me get more comfortable working with HTML and CSS. I got more practice styling different sections of a webpage, working with layouts, and adding links to other pages.
